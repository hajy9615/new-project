# 제일 IR 플랫폼 — 순천제일대학교 IR·사업비 통합 관리 (시범판)

청강문화산업대(사업비 행정 지원 도구)와 연암공대(결재 기록 기반 행정 인사이트) 사례의 강점을 합치고, 두 사례에 없던 기능을 더한 단일 파일 웹앱.

- 파일 하나(`ir/index.html`)로 동작. 서버·설치 불필요.
- 처음에는 **예시 데이터**로 열림. `자료·설정`에서 실제 엑셀을 올리면 바뀜.
- 자료는 각자의 브라우저(localStorage)에만 저장됨. 백업·복원은 `자료·설정`에서 수행.

## 1. 화면 구성

| 영역 | 화면 | 출처 |
|---|---|---|
| 사업비 관리 | 종합 현황, 예산·집행 현황(영역·부서·비목·프로그램), 결재 도우미(회의비·여비·수당), 집행 기준 안내, 예산 변경 이력 | 청강 |
| | 집행 예측·경보(불용 예상), 제출 전 점검(잔액 초과·기준 초과·계좌 대조) | 추가 |
| 성과·IR | 성과지표 추이(비교군 대비), 자율성과지표·자체평가 | 청강 |
| | 예산–성과 연계, 환류 추적, 평가 증빙 묶음, 학생 성공 IR | 추가 |
| 행정 인사이트 | 확인 과제(계좌 불일치·예산 변경·분할 집행·월말 몰림·불용 위험·집행 대비 성과 부족), 사업 경로, 준비 업무 | 연암 |
| 공통 | 열람 권한 3단계, 담당자 검토 후 게시, 계좌 가명 처리, 이용 현황 기록 | 연암 + 추가 |

## 2. 자료 올리기 양식

| 자료 | 첫 행 열 이름 |
|---|---|
| 집행 내역 | 집행일, 프로그램, 비목, 금액, 거래처, 계좌, 적요 |
| 예산 배정 | 코드, 프로그램, 영역, 부서, 예산 |

계좌번호는 올리는 즉시 비교용 기호로 바뀌며 원래 번호는 저장되지 않음. 수령인·성명 열은 읽지 않음.

## 3. 실제 운영 전에 바꿔야 할 값 [확인필요]

- 사업 기간, 영역·프로그램·부서·비목 구조, 예산 배정액
- 회의비 1인당 기준, 수당 단가 기준 등 점검 기준값(대학 사업비 집행 지침 기준)
- 집행 기준 안내의 지침 문안(현재는 예시 문안, 지침 원문과 조항으로 교체)
- 정보공시 지표·비교군 값, 자율성과지표 목표·실적, 자체평가 점수, 학과별 지표

## 4. 한계

- 열람 권한은 화면 전환 방식의 미리보기임. 실제 접근 통제는 학교 계정 로그인과 서버 측 권한 확인이 필요함.
- 집행 예측은 최근 3개월 월평균 집행 속도가 유지된다고 가정한 단순 추정임.
- 집행 기준 안내는 등록된 검색어가 질문에 들어 있을 때만 원문을 보여줌. AI를 호출하지 않음.
- 성과지표·학생 IR·자체평가 자료는 현재 화면에서 올릴 수 없고 백업 내용(JSON)을 고쳐 넣어야 함.
