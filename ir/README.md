# 제일 IR 플랫폼 — 순천제일대학교 성과지표 관리 (시범판)

대학중장기발전계획 성과지표와 전문대학 기관평가인증 지표를 담당부서·신호등·일정과 묶어 관리하고, 시스템 다이내믹스 모의로 예측과 의사결정을 돕는 단일 파일 웹앱.

- 파일 하나(`ir/index.html`)와 글꼴(`ir/fonts/`)로 동작. 서버·설치 불필요.
- **실적 수치는 들어 있지 않음.** 지표 체계·목표·담당부서만 대학 공개 자료에서 미리 넣어 두었고, 실적은 올리거나 직접 입력함.
- 자료는 각자의 브라우저(localStorage)에만 저장됨. 백업·복원은 `자료 올리기·설정`에서 수행.

다른 대학 사례에서 가져온 것: 청강문화산업대(성과 현황 조회·순위, 안내 챗봇의 원문 답변, 뉴스 생성, 자료 게시판), 연암공대(흐름·이슈 지도, 반복 의견의 과제화, 선제 알림, 검토 후 확정, 근거 번호 확인).

## 2. 신호등 기준

| 대상 | 초록 | 노랑 | 빨강 | 회색 |
|---|---|---|---|---|
| 성과지표 | 달성률 100% 이상(A) | 80% 이상(B·C) | 80% 미만(D·E) | 실적 미입력 |
| 인증 정량지표 | 충족 | 기준의 90% 이상(조건부) | 미충족 | 실적 미입력 |

등급 구간(A 100%, B 90%, C 80%, D 70%)은 대학 자체평가 보고서의 정량지표 평가 등급 기준을 따름. 조건부 충족 90%는 편람 확인이 필요함.

## 4. 미리 넣어 둔 체계의 출처

- 중장기 발전계획: **대학 중장기 발전계획(VISION 2030) 개편(안) 요약(기획팀, 2026. 11. 20.)** 4~11쪽
  - 7대 핵심전략, 29개 전략과제(B5 신설, F2 개편), 52개 세부과제의 추진내용과 담당부서
  - 부서별 성과지표 52개와 연차별 달성목표(Y=2026학년도, 2026~2030), 핵심성과지표 12개
  - 목표가 ‘향상’·‘감소’로 적힌 지표 7개는 전년 실적과 비교해 판정함
- 인증 수치 지표 12개의 충족 기준, 등급 구간, 개선 과제 12건: 2025학년도 대학 자체평가 결과보고서(2026. 6.)
- 사명·비전, 부서 목록, 색상, 로고: 대학 홈페이지(2026-11-21 확인)

확인이 필요한 사항: 부속·부설기관장 겸직 비율은 목표가 30 → 20으로 낮아지므로 낮을수록 좋은 지표로 처리함. 전공교과 강좌당 학생수도 낮을수록 좋은 지표로 처리함. ‘향상’ 목표의 정확한 판정 기준, 특성화학과 대상 직무연계 취업지수의 단위와 산식, 재학생 AI 교과·비교과 이수율의 2026학년도 목표(문서에 공란)는 확인이 필요함. 교육비환원율은 계획 목표(110%)와 자체평가 보고서의 인증 기준(100%)이 다름. 개편(안)이므로 확정본과 다를 수 있음.

## 5. 시스템 다이내믹스

- 지표별 예측: 저량=지표값, 유량=추세 관성(3년마다 절반) + 개선 노력×(목표−현재)÷2년.
- 대학 모형: 재학생 수, 교육 여건·품질, 취업률, 대학 평판, 재정 여력의 5개 저량. 7대 전략의 투자 강도가 유입·유지율·취업률·교육 여건에 작용함.
- 자료 연계: 등록유지율·취업률·강좌당 학생수는 최근 실적을, 재학생 수·입학정원·충원율은 기초 현황을 초기값으로 씀. 자료가 없으면 목표값이나 지수 100으로 시작함.
- 가정 값 [확인필요]: 탄력성(0.3, 0.3, 0.5), 조정 기간(2년, 1.5년, 3년, 1년), 전략별 효과 계수, 규모–여건 관계표, 평균 수업연한 2.4년.
- 검증: 스킬의 파이썬 기준 엔진과 결과 일치(차이 0), 현행·입학자원 불변 조건에서 균형 유지, 입학정원 0이면 재학생이 0에 가까워짐, 계산 간격 절반·RK4와의 차이 0.01% 이내. 실측 자료에 대한 재현 검증은 하지 않았음.
- 모형 만들기: 변수 종류는 조정형(원인이 정한 목표를 조정 기간에 걸쳐 따라감), 외생(연 변화율), 누적(유입 − 유출)의 세 가지. 조정형의 목표 = 현재 값 × Π(원인 ÷ 원인의 현재 값)^(방향 × 세기). 관계 사전은 일반적인 가설 80건이며 기본 세기는 가정 값 [확인필요]. 고르지 않은 변수를 거치는 관계는 간접 관계로 이어 줌. 기준 엔진과 결과 일치(차이 0).
- 캘린더 밀림 모의: 대기 업무 = 이전 대기 + 그달 일정 − 월 처리 가능 건수.

## 6. 한계

- 열람 권한은 화면 전환 방식의 미리보기임. 실제 접근 통제에는 학교 계정 로그인과 서버가 필요함.
- 여러 사람이 같은 자료를 보려면 백업 내용을 주고받아야 함.
- 모의 결과는 가정 값에 따라 달라지며 정책 방향 비교용임.
