# 제일 IR 플랫폼 — 순천제일대학교 성과지표 관리 (시범판)

대학중장기발전계획 성과지표와 전문대학 기관평가인증 지표를 담당부서·신호등·일정과 묶어 관리하고, 시스템 다이내믹스 모의로 예측과 의사결정을 돕는 단일 파일 웹앱.

- 파일 하나(`ir/index.html`)와 글꼴(`ir/fonts/`)로 동작. 서버·설치 불필요.
- **실적 수치는 들어 있지 않음.** 지표 체계·목표·담당부서만 대학 공개 자료에서 미리 넣어 두었고, 실적은 올리거나 직접 입력함.
- 자료는 각자의 브라우저(localStorage)에만 저장됨. 백업·복원은 `자료 올리기·설정`에서 수행.

## 2. 신호등 기준

| 대상 | 초록 | 노랑 | 빨강 | 회색 |
|---|---|---|---|---|
| 성과지표 | 달성률 100% 이상(A) | 80% 이상(B·C) | 80% 미만(D·E) | 실적 미입력 |
| 인증 정량지표 | 충족 | 기준의 90% 이상(조건부) | 미충족 | 실적 미입력 |

등급 구간(A 100%, B 90%, C 80%, D 70%)은 대학 자체평가 보고서의 정량지표 평가 등급 기준을 따름. 조건부 충족 90%는 편람 확인이 필요함.

## 3. 자료 올리기 양식 (첫 행의 열 이름으로 종류를 구분)

| 자료 | 열 이름 |
|---|---|
| 지표 실적 | 코드 또는 지표명, 학년도, 실적 |
| 성과지표 정의·담당부서 | 지표명, 코드, 단위, 담당부서, 목표, 방향(상향·하향), 핵심(Y·N), 전략(A~G) |
| 인증 정성 평가요소 | 영역, 준거, 평가요소, 담당부서, 판정, 근거자료, 기한 |
| 일정 | 일자, 제목, 구분(평가·제출·회의·학사·기타), 담당부서, 관련지표 |
| 기초 현황 | 학년도, 재학생수, 입학정원, 신입생충원율 |

코드가 겹치는 지표(B32, B41, C22, C41)는 지표명으로 구분해 올려야 함.

## 4. 미리 넣어 둔 체계의 출처 (2026-11-21 확인)

- 7대 핵심전략·28개 전략과제, 사명·비전: 대학 홈페이지 ‘핵심전략방향체계’, ‘대학의 비전체계도’
- 성과지표 48개의 이름·목표·담당부서, 인증 정량지표 12개의 충족 기준, 등급 구간: 2025학년도 대학 자체평가 결과보고서(2026. 6.)
- 부서 목록: 대학 홈페이지 ‘부처성과목표’
- 색상: 대학 홈페이지 ‘전용색상’(Pantone 286C·300C·Cyan·355C·382C의 RGB 값). 368C는 홈페이지 표기 값이 300C와 같아 로고 이미지의 색으로 대신함
- 로고: 대학 홈페이지 머리글 로고 이미지

확인이 필요한 사항: 전공교과 강좌당 학생수와 중도탈락율은 보고서에 ‘이상’으로 적혀 있으나 낮을수록 좋은 지표로 처리함. 재정지원사업 참여 예산은 목표가 없음. 전략별 색은 비전체계도 그림을 보고 근사한 값임. 정성 평가요소는 편람 원문을 확인하지 못해 비워 둠.

## 5. 시스템 다이내믹스

- 지표별 예측: 저량=지표값, 유량=추세 관성(3년마다 절반) + 개선 노력×(목표−현재)÷2년.
- 대학 모형: 재학생 수, 교육 여건·품질, 취업률, 대학 평판, 재정 여력의 5개 저량. 7대 전략의 투자 강도가 유입·유지율·취업률·교육 여건에 작용함.
- 자료 연계: 등록유지율·취업률·강좌당 학생수는 최근 실적을, 재학생 수·입학정원·충원율은 기초 현황을 초기값으로 씀. 자료가 없으면 목표값이나 지수 100으로 시작함.
- 가정 값 [확인필요]: 탄력성(0.3, 0.3, 0.5), 조정 기간(2년, 1.5년, 3년, 1년), 전략별 효과 계수, 규모–여건 관계표, 평균 수업연한 2.4년.
- 검증: 스킬의 파이썬 기준 엔진과 결과 일치(차이 0), 현행·입학자원 불변 조건에서 균형 유지, 입학정원 0이면 재학생이 0에 가까워짐, 계산 간격 절반·RK4와의 차이 0.01% 이내. 실측 자료에 대한 재현 검증은 하지 않았음.
- 캘린더 밀림 모의: 대기 업무 = 이전 대기 + 그달 일정 − 월 처리 가능 건수.
