# 제일 IR 플랫폼 — 순천제일대학교 IR·사업비 통합 관리 (시범판)

청강문화산업대(사업비 행정 지원 도구)와 연암공대(결재 기록 기반 행정 인사이트) 사례의 강점을 합치고, 두 사례에 없던 기능을 더한 단일 파일 웹앱.

- 파일 하나(`ir/index.html`)로 동작. 서버·설치 불필요.
- 처음에는 **예시 데이터**로 열림. `자료·설정`에서 실제 엑셀을 올리면 바뀜.
- 자료는 각자의 브라우저(localStorage)에만 저장됨. 백업·복원은 `자료·설정`에서 수행.

### 3차 보강 (화면 디자인)

- 업무 영역 5개에 고유 색을 부여함(의사결정 청동, 사업비 관리 남색, 성과·IR 청록, 행정 인사이트 자주, 운영 회청). 메뉴 표지, 화면 머리띠, 패널 표식, 표 머리선, 주 버튼이 같은 색을 따름.
- 서체: 제목·큰 숫자 Noto Serif KR, 본문 Noto Sans KR.
- 인포그래픽: 예산 흐름 띠, 영역별 원형 게이지, 수치 타일의 원형 표시, 단계 흐름(결정·환류), 깔때기(조기 지원), 2×2 배치도(포트폴리오), 선 그래프 면 채움.
- 모션(M1): 화면 진입 시 패널 순차 등장, 숫자 카운트업, 막대·게이지·선 그리기, 화면 전환 페이드. 저감 모션 설정에서는 최종 상태를 바로 표시함.
- 대학 고유 색상·로고는 반영하지 않음 [확인필요]. 브랜드 지침이 있으면 `:root`의 `--navy`, `--gold`, `--a-*` 값만 바꾸면 됨.

### 4차 보강 (예측·시뮬레이션: 시스템 다이내믹스)

| 화면 | 내용 |
|---|---|
| 인과지도 | 변수 12개·연결 18개·순환 6개(균형 B1~B3, 강화 R1~R3). 순환 종류는 연결 부호의 곱으로 자동 판별. 순환 선택 시 경로 강조, 변수 끌어 옮기기, 변수별 원인·결과 조회. 구조 진단: 미봉책의 실패 |
| 저량·유량도와 산식 | 저량 9개, 유량·보조 변수 24개. 산식 목록은 모형 정의에서 자동 생성, 저량–유량 단위 자동 점검, 요소 선택 시 산식·현재 값·향후 추이 표시, 산식과 상수 직접 수정(잘못된 산식은 거부) |
| 정책 시뮬레이션 | 정책 손잡이 5개와 가정 1개를 움직이면 약 두 사업연도의 집행률·달성률·잔액·재작업률을 즉시 재계산. 정책안 저장·비교, 결정 기록 등록 |
| 정책 탐색 | 개입 지점별 효과(메도즈 개입 수준 대응), 가정 ±20% 민감도, 무작위 150회 불확실성 범위, 손잡이 조합 324가지 전수 탐색 |
| 의사결정 훈련 | 석 달 단위로 정책을 정하며 사업 종료까지 운영, 종료 후 점수와 구조 되짚기 |

모형 구조: 예산 잔액 → 집행 요청 → 집행 대기액 → 집행 완료 → (지연) 성과 달성률 → 차년도 배정. 업무 부하가 재작업률을 높이고, 독려와 연말 몰림이 운영 품질을 낮추는 경로를 포함함.

- 자료에서 자동 보정: 연간 배정액, 누적 집행액, 초기 잔액·대기액, 요청 성향, 1인당 처리액, 성과 생산성, 현재 달성률.
- 가정 값 [확인필요]: 처리 인력 3명, 기본 재작업률 12%, 사전점검 효과 60%, 성과 반영 지연 3개월, 품질 감쇠 12개월, 성과 연동 배정 민감도 0.5, 차년도 목표 상향률 0.5, 달성률 상한 150%, 부하–재작업·품질–성과 관계표.
- 검증: 스킬의 파이썬 기준 엔진(`sd_engine.py`)과 같은 조건에서 결과가 일치함(차이 0). 극한 조건(요청 성향 0, 인력 0, 잔액 0) 통과, 저량 음수 없음. 계산 간격을 절반으로 줄이면 2개년 불용 합계가 약 2.5% 달라짐(연말 반납 시점의 영향).
- 실측 자료에 대한 보정·재현 검증은 하지 않았음. 수치는 방향 비교용임.

## 2. 자료 올리기 양식

| 자료 | 첫 행 열 이름 |
|---|---|
| 집행 내역 | 집행일, 프로그램, 비목, 금액, 거래처, 계좌, 적요 |
| 예산 배정 | 코드, 프로그램, 영역, 부서, 예산 |

계좌번호는 올리는 즉시 비교용 기호로 바뀌며 원래 번호는 저장되지 않음. 수령인·성명 열은 읽지 않음.

## 3. 실제 운영 전에 바꿔야 할 값 [확인필요]

- 사업 기간, 영역·프로그램·부서·비목 구조, 예산 배정액
- 회의비 1인당 기준, 수당 단가 기준 등 점검 기준값(대학 사업비 집행 지침 기준)
- 집행 기준 안내의 지침 문안(현재는 예시 문안, 지침 원문과 조항으로 교체)
- 정보공시 지표·비교군 값, 자율성과지표 목표·실적, 자체평가 점수, 학과별 지표

## 4. 한계

- 열람 권한은 화면 전환 방식의 미리보기임. 실제 접근 통제는 학교 계정 로그인과 서버 측 권한 확인이 필요함.
- 집행 예측은 최근 3개월 월평균 집행 속도가 유지된다고 가정한 단순 추정임.
- 집행 기준 안내는 등록된 검색어가 질문에 들어 있을 때만 원문을 보여줌. AI를 호출하지 않음.
- 핵심성과지표의 명칭·목표값은 예시이며 협약서 기준으로 교체해야 함.
- 재배분 모의는 받는 프로그램이 넘겨받은 예산을 자기 예상 집행률만큼 집행한다고 가정함.
- 영수증 사진은 글자를 읽지 않으며(OCR 없음) 금액·일자는 직접 입력함.
- 성과지표·학생 IR·자체평가 자료는 현재 화면에서 올릴 수 없고 백업 내용(JSON)을 고쳐 넣어야 함.
